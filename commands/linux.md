# Linux Commands

## 現在地確認

```bash
pwd
````

## ディレクトリ移動

```bash
cd ~
cd ~/projects
```

## ファイル一覧

```bash
ls
ls -la
```

## ディレクトリ作成

```bash
mkdir dirname
mkdir -p parent/child
```

## ファイル作成

```bash
touch file.md
```

## ファイル表示

```bash
cat file.md
```

## コピー

```bash
cp source.txt dest.txt
```

## 移動・リネーム

```bash
mv old.txt new.txt
```

## 削除

```bash
rm file.txt
rm -r dirname
```

## パッケージ更新

```bash
sudo apt update
sudo apt upgrade -y
sudo apt autoremove -y
```
