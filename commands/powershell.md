# PowerShell Commands

## WSL状態確認

```powershell
wsl -l -v
````

## WSL起動

```powershell
wsl
```

## Ubuntu指定起動

```powershell
wsl -d Ubuntu-22.04
```

## WSL完全停止

```powershell
wsl --shutdown
```

## wingetでインストール

```powershell
winget install --id Microsoft.VisualStudioCode
```

## PowerShellバージョン確認

```powershell
pwsh --version
```
